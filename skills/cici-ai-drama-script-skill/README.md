# Cici AI Drama Script Skill

抖音 AI 短剧家族的剧本责任分支。只维护故事、钩子、情绪、血肉、逻辑和密度；视觉资产与逐镜生产交给兄弟 Skill。

## 安装

`npx skills add wshicheng851-tech/cici-ai-drama-skill-family`

## 你可以直接这样说

“检查这份抖音 AI 短剧剧本的钩子、人物弧线、逻辑和事件密度。”

## 验证

运行 `validate_skill.py` 并查看 `reports/trigger-eval.json`。

## Troubleshooting

如需资产或逐镜提示词，请转交对应子 Skill，不在剧本阶段混写。
