# 抖音 AI 短剧剧本系统

## 四类钩子

- 结果先给：先展示异常结果，再追问如何发生；适合悬疑、逆袭、关系崩塌。
- 信息错位：观众知道角色不知道，或角色知道观众不知道；适合误会、秘密、身份反转。
- 关系异常：称谓、站位、行为与既有关系冲突；适合情感、家庭、职场。
- 规则/物件异常：熟悉空间出现不合理规则或物件；适合悬疑、奇幻、高概念。

钩子必须记录“承诺的问题”和“兑现时间”。第一秒可用可见动作、物件、字幕或声音承载，不能只靠标题补足。

## 情绪波形

波形是因果设计工具而非装饰：

1. 阶梯上升：每次成功暴露更大代价。
2. 锯齿反转：局部胜利与新证据交替。
3. 先甜后坠：先建立值得失去的关系，再让选择造成损失。
4. 压抑后释放：阻力层层封堵，最终通过角色行动释放。
5. 误会剥洋葱：每次解释纠正一层认知并带来新问题。
6. 循环升级：重复同一事件结构，但条件、风险和意义逐次变化。

## 血肉自检

| 项 | 通过问题 |
|---|---|
| 钩子 | 现实中的人会在此情境说或做吗？ |
| 冲突 | 双方各自失去什么具体东西？ |
| 落点 | 关掉对白后，结尾是否仍看得见？ |
| 金句 | 这句话是否只能由此人此刻说出？ |
| 细节 | 是否有至少三处具体生活痕迹？ |
| 低谷 | 是否由至少两个连续障碍和一次选择构成？ |

## 逻辑可信度 A1–A6

- A1 信息来源：角色知道的每个关键事实都能指向看见、听见、被告知、查到或合理推断的镜头。
- A2 身份约束：年龄、职业、经济能力、关系和权限限制其行为。
- A3 因果闭合：每个关键结果有动作或决定作为前因。
- A4 重大决定：高成本行为需要动机、犹豫或逼迫，不能一步跳到极端。
- A5 现实可行：核算时间、路程、支付、通讯、空间和物理条件。
- A6 巧合边界：巧合可触发相遇，不可连续提供线索并解决冲突。

## 事件密度 B1–B6

- B1 每 6–12 秒至少出现一个有效信息点；慢段可放宽，但需有情绪或关系推进。
- B2 至少两条推进线：外部目标/阻碍与关系/认知变化。
- B3 每个障碍除拖慢目标外，还暴露信息或迫使选择。
- B4 关键对白必须改变认知、关系、资源或下一步行动。
- B5 后 1/3 不得靠重复争吵、走路或沉默凑时长。
- B6 信息点总量按实际时长核算；3–4 分钟通常需约 25–35 个可识别信息点，但以可演密度为准。

## 逻辑链表字段

关键信息/行为、来源镜头或铺垫、角色身份约束、时间路程核算、因果后果、风险、修正。

## 信息点时间轴字段

秒点、信息点、类型（事实/关系/目标/障碍/选择/结果）、承接前项、引出后项、是否重复。
