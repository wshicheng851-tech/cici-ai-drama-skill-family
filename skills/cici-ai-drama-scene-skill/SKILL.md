# Cici AI 短剧场景 Skill

场景不是背景图，而是角色能行动、镜头能换位、连续性可核对的空间。继承 Style ID，但把时间、地点和空间内容独立维护。

## 场景拆解

先去重母场景，再把晨/夜、晴/雨、营业/停电等定义为 `SCENE-ID` 变体，避免把同一地点重复建模。信息不足时给 A/B/C 三种空间方案，至少在布局、动线、视觉中心和纵深中有 2–3 项差异。

场景公式：时代/季节/时段 + 自然或建筑环境 + 空间结构与动线 + 材料与陈设 + 光源 + 天气物理影响 + Style ID。

至少锁三个空间锚点，并记录入口出口、角色路线、前中后景、视觉中心、遮挡、可放机位和反打方向。天气必须作用于地面、空气、玻璃、衣物或光线，不能只写“下雨”。

## 母版与测试

输出固定项、变量、禁改项、平面关系文字图、时段/天气变体和风险。标准测试：大全景、中景活动区、关键细节、反向视角；所有视角的门窗、货架、光源和动线应闭合。
