# v1.4.0 → v2.0.0 迁移与去重表

| 旧内容/新来源 | v2 唯一归属 | 处理 | 理由 |
|---|---|---|---|
| 立项、锁案、投资人审批 | 总控 + 剧本 | 总控保留审批；创作细则移至剧本 | 避免总控重复编剧方法 |
| 抖音四派钩子、六套情绪波形、系列方法 | 剧本 | 保留并整合 | 属于选题与故事开发 |
| 血肉质检六条 | 剧本 | 保留 | 应在写作时前置，不等终检补救 |
| 逻辑可信度 A1–A6、事件密度 B1–B6 | 剧本 | 保留 | 属于因果与时长可演性 |
| 新包的 Want/Need、六节点、因果链、场景化 | 剧本 | 补充缺项 | 强化结构诊断与可拍转换 |
| 原视觉圣经总体规则 | 风格、角色、场景、道具 | 拆分 | 各资产由独立责任分支维护 |
| 新包的 Style DNA 与三方案/问答双模式 | 风格 | 补充 | 原版缺少系统化风格锁定流程 |
| 新包的人物固定/可变/禁改及标准测试 | 角色 | 补充 | 强化生成一致性验收 |
| 新包的可导航空间、天气物理影响 | 场景 | 补充 | 原版缺少空间逻辑与场景母版验证 |
| 新包的道具类型、人机交互、母版多状态 | 道具 | 补充 | 原版道具方法较薄 |
| 原连续性、逐镜表、三层提示词、剪辑声音 | 分镜 | 合并去重 | 均属于镜头编译与成片节奏 |
| 原试拍、漂移诊断与终检 | 质检 | 合并去重 | 独立为发布前验证职责 |
| 新包的 SCRIPT FACT/INFERENCE/DESIGN、资产矩阵/状态/P0-P3/DIFF | 总控 | 补充 | 支撑多子 Skill 协作和增量更新 |
| 文艺作者模式及其触发/回归用例 | 不进入活跃 v2 | 淘汰 | 用户明确只保留抖音创作板块 |
| 新包中的 TVC、MV、长片通用分支 | 不进入活跃 v2 | 拒绝 | 超出本 Skill 的抖音 AI 短剧范围 |

## 去重原则

相同知识只在上表指定分支保留一次。总控仅保留路由、状态、审批和依赖，不复制各分支方法；子 Skill 通过 ID、锁定卡和变更单协作。
