# 镜头编译规则

## 镜头原子

一个镜头尽量只承载一个主要动作和一个信息任务。复杂动作拆成起始、过程、结果；若模型不稳定，改为首尾帧或多个短镜头。

## 连续性记录

前镜尾状态 → 本镜必须继承 → 本镜允许变化 → 变化原因 → 本镜尾状态。涉及左右方向、门窗位置、手持物、伤痕、湿度和光源时必须写明。

## 提示词模板

`[固定 Style/资产] + [本镜时空与状态] + [主体动作和可见情绪] + [构图/景别/机位/镜头运动] + [起止状态与叙事功能] + [连续性与禁改项] + [负面约束]`

## 节奏检查

相邻镜头若信息功能、景别和运动都相同，优先合并或制造对比。平均镜头时长只是结果指标；不能为了命中 2.0–2.7 秒而切碎需要表演的关键对白。
