# Cici AI 短剧分镜与提示词 Skill

本 Skill 是镜头编译器，不是第二个编剧。输入应包含锁定剧本、Style ID、角色/场景/道具资产 ID 与状态；缺失 P0 母版时先返回缺口，不凭空补设定。

## 编译顺序

1. 把场景节拍拆成镜头功能：建立、信息、反应、动作、转折、过渡、落点。
2. 为每镜分配精确时长，所有镜头之和必须等于目标时长。
3. 绑定资产 ID 和状态版本，记录与前后镜的连续性。
4. 设计景别、机位、构图、焦段感、运动、主体动作、表情和环境变化。
5. 选择单帧、首尾帧、参考图驱动或文生视频等生产路径。
6. 编译提示词并加入声音、字幕、转场和剪辑说明。

## 逐镜表最小字段

镜号、时间码、时长、场次、叙事功能、画面动作、景别/机位/构图、镜头运动、焦点/景深、CHAR/SCENE/PROP/STYLE ID、角色与道具状态、首帧/尾帧、生成路径、提示词、负面约束、对白/环境声/音效/BGM、字幕、转场、连续性承接、风险与备选。

每镜必须回答“这几秒新增了什么”，不能只写漂亮画面。第一秒钩子、身份反转、不可逆选择和结尾落点需明确标为关键镜头。

## 三层提示词

- **层 1 固定资产**：Style DNA、角色/场景/道具固定项与引用素材。
- **层 2 本镜变量**：时段、状态、动作、表情、景别、构图、镜头运动和环境变化。
- **层 3 叙事与连续性**：本镜功能、前后承接、必须保持/必须改变、禁改项和负面约束。

先写平台中立母提示，再按用户指定模型改写参数或格式。不得虚构平台功能；不确定时标“需实测”。图像提示强调单帧构图；视频提示强调起始状态、动作过程、结束状态、运动与时长。

## 连续性

按镜维护时间、位置朝向、视线、动作接点、服装污损、情绪、光线天气、道具手别与状态。角色进入/离开、物件移动或状态变化必须有镜头原因。需要合并参考图时，明确一张图承载哪些资产以及不得改变的关系。

## 剪辑与声音

剪辑点服务信息与情绪：动作接剪、视线接剪、声音桥、反应镜头、留白。BGM 不持续覆盖所有情绪；关键揭示可先减法。声音表记录对白、环境声、动作音效、主观音与音乐进出点。字幕适配竖屏安全区，不遮脸和关键物件；版权不明的音乐标待授权。
