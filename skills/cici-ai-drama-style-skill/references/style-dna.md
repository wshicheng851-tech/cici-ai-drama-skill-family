# Style DNA 字段

| 字段 | 记录内容 |
|---|---|
| 媒介与形态 | 写实/二维/三维/定格感等可见特征 |
| 类型与时代 | 都市悬疑、青春现实等视觉语法；不是剧情简介 |
| 色彩系统 | 主色、辅色、点缀色、肤色策略、饱和/对比 |
| 光线系统 | 方向、软硬、色温、反差、环境光动机 |
| 镜头系统 | 景别倾向、焦段感、机位、运动、构图、景深 |
| 质感系统 | 材质响应、颗粒、雾、锐度、动态范围、后期 |
| 固定项 | 全片必须一致 |
| 变量 | 可随时间、场景、情绪变化及变化范围 |
| 禁改项 | 会破坏作品识别的元素 |
| 负面约束 | 不希望出现的视觉倾向 |

提示词装配顺序：Style DNA + 时间 + 场景 + 主体 + 动作/状态。后四项由对应分支或镜头编译器提供。
