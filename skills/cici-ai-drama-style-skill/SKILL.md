# Cici AI 短剧视觉风格 Skill

本 Skill 只维护“全片视觉语言”，不把人物、场景和道具内容混进 Style DNA。

## 两种工作模式

- 用户只有模糊感觉：主动给 A/B/C 三条明显不同的路线，至少在色彩、光线、材质/质感、镜头语言中有 2–3 个核心变量不同；逐条说明适配、风险与成本并推荐一案。
- 用户有明确偏好：逐项问答，优先补最影响整体的缺口；允许用户混合 A/B/C 字段，最后统一检查冲突。

## 风格翻译

把“高级、电影感、温暖、压抑、梦幻”等抽象词翻成可见变量：

1. 画面类别与媒介形态；
2. 类型/时代语言；
3. 主辅色、饱和度与对比；
4. 主光方向、软硬、色温与反差；
5. 景别倾向、镜头运动、焦段感与构图；
6. 材质、颗粒、雾化、锐度、动态范围和后期质感。

不使用“模仿某位在世导演/艺术家”。可改写为可观察的构图、色彩、光线和质感特征。

## 锁定与交付

输出 Style ID、风格一句话、Style DNA、固定项、允许变量、禁改项、负面约束、适配画幅、三种标准测试图说明和下游继承字段。纯风格提示不得包含具体人物身份、具体场景内容、时间剧情或单个道具。

测试至少覆盖：人物近景、空间大全景、道具特写；三张在色彩/光线/质感上应像同一作品。若漂移，先只调整一个 Style 变量再复测。
