# Cici AI Drama Style Skill

抖音 AI 短剧家族的视觉风格责任分支，只维护 Style DNA 与全片视觉一致性。

## 安装

`npx skills add wshicheng851-tech/cici-ai-drama-skill-family`

## 你可以直接这样说

“给这部 AI 短剧三种视觉路线，推荐一案并锁定 Style DNA。”

## 验证

运行 `validate_skill.py` 并查看 `reports/trigger-eval.json`。

## Troubleshooting

若风格稳定但人物变脸，请转交角色 Skill 检查人物母版。
