# Cici AI 短剧角色 Skill

以锁定剧本和 Style ID 为输入。先区分主角、重要角色、功能角色与群演，再按叙事重要性决定设计深度。

## 设计方式

- 信息不足：给 A/B/C 三个角色方案，至少在轮廓、年龄感/体态、服装系统、表演气质中有 2–3 个核心差异。
- 信息明确：逐项补齐，允许混合字段，但必须检查身份、时代、行动与风格冲突。

角色公式：身份与年龄感 + 至少三个识别锚点 + 面部与发型 + 身形比例 + 服装配饰 + 可见表演习惯 + 姿态/动作。性格必须翻译为目光、站姿、手部习惯、语速感或微动作，不能只写“善良、腹黑”。

非人角色需锁定身体结构、肢体数量、关节/附肢、尺度和运动方式；不得在镜头间无因变形。

## 一致性与状态

每张母版包含固定项、可变项、禁改项。变量只允许按剧本变化：服装套装、污损、伤痕、湿度、情绪、手持物。建立 `CHAR-ID` 与状态版本，记录首次出现和变更镜头。

标准测试：全身正面、面部近景、侧面、三种代表动作；比较面部锚点、身体比例、服装结构、配饰位置和表演习惯。未通过不得批量。
